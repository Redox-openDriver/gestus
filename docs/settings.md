# Настройки gestus

Настройки — файл TOML. У каждой функции свой раздел и свой выключатель `enabled`; всё выключено, пока не включишь,
а без файла работает обычный набор: указатель, тапы, клик по числу пальцев, прокрутка двумя пальцами. Время — в
миллисекундах, расстояния — в миллиметрах на площадке. Неизвестный раздел, параметр или действие — это ошибка с
номером строки и столбца, а не тихое значение по умолчанию. Пример, где включено почти всё, —
[`example.toml`](example.toml).

```rust
let (config, learned) = gestus::config::load(Path::new("gestures.toml"))?;
let mut gestures = Gestures::with_symbols(config, surface, &learned);
```

## Родной режим
`Gestures::native()` — для систем, где обычные жесты уже делает своя библиотека (на Linux — libinput, и её
настраивают GNOME, KDE и другие окружения). Тогда работают только разделы, которых у системы нет: `corners`,
`rails`, `circular`, `edge-swipes`, `joystick`, `symbols`, `numpad`, `cover`, `shake`, `dwell`, `smoothing`,
`tablet`, `edge-motion`; а `pointer`, `taps`, `inertia`, `throw`, `drag`, `swipes`, `rotate`, `pinch`, `sniper`,
`knock`, `areas` и `typing` не действуют. `Config::native_extras` говорит, включён ли хоть один из работающих.

Движок сообщает, какие касания показывать системе (`visible`, `hidden`). Касание, которое может оказаться жестом,
скрыто, пока не сдвинется или не нажмёт площадку; нажатие проходит всегда; короткий тап, которого система не видела,
движок отдаёт событием `Event::Touch`, чтобы драйвер повторил его для системы. Неподвижное касание не показывается
только потому, что прошло время, — иначе долгое касание стало бы для системы тапом.

## Действия
Там, где в настройках стоит действие, можно написать:

| что | примеры |
|---|---|
| щелчок | `left-click`, `right-click`, `middle-click` |
| переключатели | `toggle-touchpad` (выключить и включить тачпад), `numpad` (цифровой блок), `tablet` (режим планшета) |
| рисование символа | `draw` — следующий штрих одним пальцем распознаётся как символ |
| клавиша | `volume-up`, `mute`, `play-pause`, `brightness-up`, `print`, `calculator`, `browser`, `files`, `lock-screen`, `f11`, `7`, `kp-plus`… |
| сочетание | `ctrl+shift+t`, `super+page-down`, `alt+tab` — до четырёх клавиш через `+` |
| готовые имена | `back`, `forward`, `copy`, `paste`, `cut`, `undo`, `redo`, `save`, `find`, `close`, `new-tab`, `reopen-tab`, `next-tab`, `previous-tab`, `refresh`, `fullscreen`, `overview`, `switch-window`, `zoom-in`, `zoom-out`, `zoom-reset`, `locate`, `rotate-right`, `rotate-left` |
| ничего | `none` |

Клавиши `calculator`, `browser`, `mail`, `files`, `search`, `lock-screen` — это мультимедийные клавиши: окружения
рабочего стола сами открывают по ним калькулятор, браузер, почту, файлы, поиск и блокируют экран. Программ библиотека
не запускает: действие — это щелчок, клавиша, сочетание или переключатель режима.

Модификаторы: `ctrl`, `shift`, `alt`, `super` (он же `win`, `meta`). Все имена клавиш — в [`src/keys.rs`](../src/keys.rs).

## Ползунки
Рейки, круговая прокрутка, поворот и щипок — это ползунки: движение превращается в шаги, каждый шаг — действие.
Значение — готовое имя или пара действий «вперёд, назад»:

| имя | вперёд / назад |
|---|---|
| `volume` | громче / тише |
| `brightness` | ярче / темнее |
| `zoom` | крупнее / мельче |
| `tabs` | следующая / предыдущая вкладка |
| `history` | вернуть / отменить |
| `tracks` | следующий / предыдущий трек |
| `rotate` | повернуть вправо / влево (`ctrl+r`, `ctrl+shift+r`; в браузере это перезагрузка) |
| `scroll` | плавная прокрутка вместо шагов |
| `none` | ничего |
| `["ctrl+tab", "ctrl+shift+tab"]` | любая своя пара |

«Вперёд» — это вверх, вправо, по часовой и разведение пальцев.

## Разделы
Время — в миллисекундах, расстояния — в миллиметрах на площадке (она 117 × 72 мм).

### `[pointer]` — указатель, тапы и прокрутка
Обычный набор, всегда включён. `speed` 4.0 — скорость; `acceleration` 3.0 — во сколько раз быстрее при резком
движении; `natural-scroll` false — естественная прокрутка; `scroll-speed` 6.0; `tap` true — тап вместо нажатия;
`tap-time` 220 — самый долгий тап; `tap-travel` 2.5 — насколько палец может сдвинуться за тап. Остальное —
пороги от ладони и большого пальца, снятые с записей: `thumb-zone`, `rest-time`, `rest-travel`, `edge`,
`edge-rest-time`, `side-edge`, `bottom-edge`, `edge-release`, `follow`, `scroll-start`, `swipe-start`, `slow`,
`fast`, `gap`, `multi-tap-time`.

### `[inertia]` — прокрутка по инерции
Смахнул двумя пальцами и отпустил — страница едет дальше и плавно тормозит; касание останавливает. `friction` 3.0 —
трение (больше — короче путь), `start` 60 — с какой скорости пальцев начинается полёт (мм/с), `stop` 3 — на какой
скорости он кончается. Срабатывает только после настоящей прокрутки двумя пальцами, не после свайпа.

### `[throw]` — бросок курсора
То же для указателя: резкий взмах одним пальцем докатывает курсор дальше. `friction` 6.0, `start` 250, `stop` 15.

### `[taps]` — тапы по числу пальцев
`one` left-click, `two` right-click, `three` middle-click, `four` middle-click — любое действие, например
`three = "draw"`. `drag` false — тап и сразу касание с движением тащит, как в libinput; два тапа подряд дают
двойной щелчок; `drag-time` 180 — сколько ждать второго касания. `window` 300 — пауза между тапами в узоре углов.

### `[corners]` — углы
Квадраты `size` 10 мм в каждом углу; для каждого угла свои `tap`, `double-tap` и `hold`:

```toml
[corners]
enabled = true

[corners.top-left]
double-tap = "toggle-touchpad"
```

Двойное касание в левом верхнем углу выключает тачпад, как клавиша на клавиатуре; выключенный тачпад слушает только
это же касание. Удержание (`hold-time` 1000) срабатывает, если палец один на площадке и не сдвигается. Тап в углу,
у которого есть двойное касание, превращается в щелчок с задержкой 0.3 с: драйвер ждёт, не будет ли второго.
Нижние углы задеваются чаще, лучше назначать верхние.

### `[knock]` — код постукиванием
Последовательность тапов по четвертям площадки: 1 — левая верхняя, 2 — правая верхняя, 3 — левая нижняя,
4 — правая нижняя.

```toml
[knock]
enabled = true
codes = { 1214 = "lock-screen", 4321 = "toggle-touchpad" }
```

Код из `toggle-touchpad` включает выключенный тачпад. Пока раздел включён, одиночный тап щёлкает через 0.45 с
(`window`): драйвер ждёт продолжения кода.

### `[drag]` — перетаскивание тремя пальцами
Три пальца тащат окно или выделяют текст без нажатия. Отпустил — через `grace` 500 мс бросает; коснулся раньше —
продолжает. Тап во время перетаскивания сразу бросает. `fingers` 3, `start` 3 — с какого сдвига начинать.
Свайпы тремя пальцами при этом не работают, остаются четырьмя.

### `[edge-motion]` — движение у края
Пока перетаскиваешь (нажатием, тремя пальцами или тапом), палец у края (`width` 5) двигает курсор дальше в ту же
сторону со скоростью `speed` 40.

### `[swipes]` — свайпы
Действия на конец свайпа по направлению: `[swipes.three]` и `[swipes.four]` с `left`, `right`, `up`, `down`.
`switcher = 3` — переключение окон тремя пальцами, как в Windows: Alt зажат, пока пальцы на площадке, каждые
`step` 12 мм — следующее окно.

### `[rails]` — рейки у краёв
Два пальца у левого и правого края, ведёшь вверх-вниз — `sides`; у верхнего и нижнего края, ведёшь вбок —
`top-bottom`. Один палец вдоль края — `left`, `right`, `top`, `bottom`; `right = "scroll"` — прокрутка у края, как
на старых тачпадах. `width` 10 — ширина рейки, `step` 4 — мм на шаг.

```toml
[rails]
enabled = true
sides = "volume"
top-bottom = "brightness"
```

### `[circular]` — круговая прокрутка
Начни у края и веди пальцем по кругу — прокрутка идёт без конца, по часовой вниз. `action` scroll или любой
ползунок: `volume` превращает площадку в ручку громкости. `width` 8, `step` 30 — градусов на шаг, `turn` 90 —
сколько миллиметров прокрутки даёт полный круг. Если включена, рейки одним пальцем не работают.

### `[rotate]` и `[pinch]` — поворот и щипок
Два пальца поворачиваются — `rotate` (`action` volume, `step` 30°); сходятся и расходятся — `pinch` (`action` zoom,
`step` 6 мм). Для картинок: `action = "rotate"`. Прокрутка двумя пальцами начинается сразу, как и без этих разделов.
Если пальцы идут не вместе, движок ждёт: поворот — линия между пальцами повернулась хотя бы на 10°, щипок —
расстояние между ними изменилось хотя бы на 3 мм. Второй палец при этом тоже должен сдвинуться хотя бы на полмиллиметра:
если быстрый прошёл 5 мм, а второй всё ещё лежит, это указатель. Если ни поворота, ни щипка не набралось, пока быстрый
палец не прошёл 10 мм, это тоже указатель; накопленное движение он получает разом и без ускорения.

### `[symbols]` — нарисуй символ
Сначала действие `draw` (например, `taps.three = "draw"` или двойное касание угла — в родном режиме тапы
принадлежат системе, поэтому там работает только угол), затем один штрих одним пальцем. Встроенные символы:
`circle`, `check`, `caret` (∧), `v`, `less` (<), `greater` (>), `z`, `s`, `c`, `l`, `m`, `w`, `triangle`, `square`,
`star`, `heart`, `infinity`. Ориентация важна: `<` и `∧` разные. `threshold` 0.8 — насколько похоже, `timeout`
3000 — сколько ждать штриха. Тап или второй палец отменяют рисование.

```toml
[symbols]
enabled = true

[symbols.actions]
circle = "calculator"
check = "save"
heart = "play-pause"
```

Свои символы лежат в `symbols.toml` рядом с файлом настроек: записи `[[symbol]]` с именем и точками штриха, их
пишет и читает `config::entry` и `config::templates`, а записывает драйвер своей командой (в
[elantp-327e](https://github.com/Redox-openDriver/elantp-327e) — `elantp-dev learn`). Свой символ с именем
встроенного добавляется к нему как ещё один образец. Круг и квадрат похожи сильнее остальных; если путаются, выучи
свой вариант.

### `[numpad]` — цифровой блок
Включается действием `numpad` (например, удержанием угла). Пока он включён, тап одним пальцем печатает клавишу
под пальцем, указатель и остальные жесты работают. Сетка по умолчанию:

```
7  8  9  /  ⌫
4  5  6  *  ⌫
1  2  3  -  ↵
0  0  .  +  ↵
```

`rows` — своя сетка, строки разной длины можно. Точка — `dot`; в русской раскладке она даёт «ю», для запятой и точки
там подходит `slash`.

### `[sniper]` — снайперский режим
Второй палец лежит неподвижно — курсор движется в `factor` 0.35 раза медленнее.

### `[joystick]` — джойстик
Палец, поставленный в угол `corner` (по умолчанию `bottom-right`, зона `size` 20 мм), работает как TrackPoint:
сдвинул и держишь — курсор едет сам, быстрее при большем сдвиге (`speed` 25, мёртвая зона `dead` 1 мм).

### `[dwell]` — клик задержкой
Для тех, кому трудно нажимать: остановил курсор после движения на `travel` 8 мм — через `time` 800 мс щелчок.

### `[smoothing]` — сглаживание дрожания
Фильтр 1€: убирает дрожь пальца и почти не добавляет задержки. `cutoff` 2.0 Гц — меньше значит сильнее,
`beta` 0.05 — насколько быстро фильтр отпускает при быстром движении.

### `[cover]` — накрыть ладонью
Ладонь легла на тачпад и лежит `time` 500 мс — `action` (play-pause). Тачпад должен сам отметить ладонь, и сразу:
если первые 150 мс на площадке только пальцы, это не накрытие. Многие тачпады, как ELAN 04F3:327E, отдают всю ладонь
одним-двумя касаниями, поэтому `contacts` (1) — сколько касаний нужно хотя бы, а меняться их число может. Ладонь
должна лечь дальше 8 мм от края площадки: у самого края лежит рука, которая печатает или жмёт кнопку, а не накрывает
тачпад, даже если потом сползает внутрь. Пока ладонь устраивается, она может съехать до 20 мм, а нажать площадку можно: уверенно накрывшая
рука её продавливает. Не считается, если палец водит указатель или ладонь легла меньше чем через секунду после нажатия
клавиши: так ладонь лежит при наборе текста, и накрытием она не станет, пока её не поднимут. О нажатиях сообщает
драйвер (`Gestures::typed`), в родном режиме тоже; без них ладонь при наборе от накрытия не отличить. Короткие касания
пальцами накрывающей руки тапами не считаются, а после срабатывания всё до подъёма руки ей и принадлежит. Пороги
подобраны по записям накрытий всей ладонью и краем ладони, по записи набора текста и по записи кликов.

### `[shake]` — встряхнуть курсор
Поводил курсор туда-сюда — `action` (`locate` нажимает Ctrl: в GNOME так показывается курсор, если включено
«Показывать расположение указателя»). `turns` 5 разворотов за `window` 900 мс, каждый размах от `amplitude` 6 мм
и хотя бы вдвое длиннее, чем путь вверх-вниз за то же время: круги не считаются. Во время перетаскивания не
срабатывает.

### `[tablet]` — режим планшета
Включается действием `tablet`. Площадка соответствует всему экрану, палец — перо: движок выдаёт `Event::Pen` с
положением от 0 до 1, а драйвер показывает его системе пером или абсолютным указателем. Рисует нажатие площадки или,
с `draw-on-touch = true`, само касание.
Три пальца — выход.

### `[edge-swipes]` — смахивание от края
Палец ставится у самого края (`width` 3) и уходит внутрь на `distance` 10 мм быстрее `time` 400 мс: `left` — от
левого края (например, `back`), `right`, `top`, `bottom`.

### `[areas]` — правая кнопка в углу
Нажатие площадки в правом нижнем углу — правый щелчок, в остальных местах — левый, как на ноутбуках с Windows.
`width` 0.4 — доля ширины справа, `height` 15 мм снизу. Клик по числу пальцев при этом выключается.


### `[typing]` — тачпад замолкает при наборе
Касание, начатое в течение `quiet` 500 мс после нажатия клавиши, игнорируется целиком; касание, начатое раньше,
продолжает работать. Модификаторы и сочетания с ними не считаются. О нажатиях движку сообщает драйвер
(`Gestures::typed`); в родном режиме этот раздел не действует — там его делает система, но сообщать о нажатиях стоит и
там: по ним `cover` узнаёт ладонь при наборе. Нужны ли движку нажатия, говорит `Config::uses_typing(native)`: драйверу
незачем открывать клавиатуру, если ни один из этих разделов не включён.
